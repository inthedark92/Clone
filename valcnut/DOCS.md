# Valcnut MMORPG - Документация (Django)

## ВАЖНО: Исправление ошибки "no such column: users_user.level"
Эта ошибка возникает, когда база данных (SQLite) не синхронизирована с текущими моделями Django. Поскольку мы перешли на **единую модель User**, вам необходимо полностью сбросить базу данных и пересоздать миграции.

### Как исправить (Инструкция):
1. Закройте запущенный сервер (Ctrl+C).
2. Выполните скрипт очистки (я добавил его в проект):
   ```bash
   python clean_db.py
   ```
   *Если скрипт не запускается, просто удалите вручную файл `db.sqlite3` и все файлы `000x_initial.py` в папках `migrations` всех приложений.*
3. Создайте новые миграции:
   ```bash
   python manage.py makemigrations users items battles core
   ```
4. Примените их:
   ```bash
   python manage.py migrate
   ```
5. Создайте администратора:
   ```bash
   python manage.py createsuperuser
   ```
6. Запустите сервер:
   ```bash
   python manage.py runserver
   ```

## 1. Структура проекта
- `apps/users/`: Единая модель Игрока (`User`), регистрация, авторизация.
- `apps/battles/`: Боевой движок и логика.
- `apps/items/`: Система предметов и инвентарь.
- `apps/core/`: Локации и навигация.
- `templates/`: HTML шаблоны.

## 2. Основные возможности
- **Регистрация:** При регистрации создается полноценный игровой персонаж со стартовыми характеристиками.
- **Интерфейс:** После входа доступна панель с HP/MP, золотом и навигацией.
- **Локации:** Перемещение между Ареной, Таверной, Рынком и т.д.
- **Инвентарь:** Просмотр вещей в инвентаре.

## 3. Требования
- Django >= 5.1.0
- Channels (WebSockets)
- SQLite (по умолчанию) или PostgreSQL
